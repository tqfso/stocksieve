# 趋势埋伏：缩量整理

寻找上升趋势中的窄幅整理，观察周期为1～4周。以下参数为待回测初稿，计算遵循[共用规则](README.md)。

## 入选条件

记 `B = max(H(t-20), …, H(t-1))`、`P = min(L(t-20), …, L(t-1))`，分别为此前20日区间上下沿。以下条件全部满足：

| 条件 | 公式 |
| --- | --- |
| 趋势保持 | `MA(20,t) ≥ MA(60,t)`，且 `MA(60,t) ≥ MA(60,t-5)` |
| 区间收窄 | `B / P - 1 ≤ 12%` |
| 成交减少 | `均额(5,t) / 均额(20,t) ≤ 0.8` |
| 尚未突破且接近上沿 | `P ≤ C(t) ≤ B`，且 `0 ≤ (B - C(t)) / B ≤ 3%` |

## 结果展示

- 展示区间下沿P、上沿B、区间宽度、距上沿幅度、成交额比例和“等待中”。
- 按距上沿幅度从小到大排序；入选理由示例：“上升趋势中缩量整理，距区间上沿1.8%，近5日均额为近20日的68%。”
- 后续收盘价超过本次B时，结束本次区间内等待，重新检查短线全部条件，不自动认定放量突破成立。
- 后续收盘价低于本次P，或趋势条件不再满足，本次等待信号失效。参考价按入选日固定，复查时统一复权口径。
