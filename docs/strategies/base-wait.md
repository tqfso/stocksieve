# 低位筑底：筑底观察

寻找下跌后在历史较低区域横盘、近期停止创新低的股票，观察周期为2～8周。“低位”是相对历史价格的位置。以下参数为待回测初稿，计算遵循[共用规则](README.md)。

## 入选条件

此前20日区间上下沿为 `B = max(H(t-20), …, H(t-1))`、`P = min(L(t-20), …, L(t-1))`；此前120日最高、最低价为 `H120`、`L120`。以下条件全部满足：

| 条件 | 公式 |
| --- | --- |
| 趋势尚待修复 | `MA(20,t) < MA(60,t)` |
| 位于历史低区 | `H120 > L120`，且 `0 ≤ (C(t) - L120) / (H120 - L120) ≤ 35%` |
| 区间收窄 | `B / P - 1 ≤ 12%` |
| 近期未创新低 | 最近5日（含当日）最低价不低于此前15日最低价，即 `min(L(t-4), …, L(t)) ≥ min(L(t-19), …, L(t-5))` |
| 成交减少 | `均额(5,t) / 均额(20,t) ≤ 0.8` |
| 尚未突破 | `P ≤ C(t) ≤ B` |

## 结果展示

- 展示区间上下沿、区间宽度、120日区间位置、成交额比例和“等待中”；区间位置0%对应历史最低价，100%对应最高价。
- 按120日区间位置从低到高排序；入选理由示例：“处于120日价格区间的24%位置，近5日未创新低，成交额比例为65%，等待筑底确认。”
- 后续收盘价超过本次B时，结束本次区间内等待，重新检查短线全部条件；MA20升至MA60及以上时重新检查趋势埋伏条件。
- 后续收盘价低于本次P，本次筑底等待信号失效；其余入选条件不满足时不再进入当日名单。参考价按入选日固定，复查时统一复权口径。
