# AI 分析专项评审

本轮保留基本面、筹码、买卖建议三类分析，补齐按需联网取资料带来的任务过程和结果展示。报告文档导出属于后续扩展，本期评审网页阅读、历史和复制体验。

三类分析的数据、判断范围及股东减持检查见独立的 [AI 分析设计](ai-analysis-design.md)。

## 交互约定

1. 在个股详情选择分析类型后主动发起；买卖建议沿用当前策略。按需补充公告、财报和相关新闻，无需用户配置检索工具。
2. 受理后展示排队、获取资料、分析研判、整理报告四个阶段。阶段表示当前处理内容，不承诺固定耗时；正式状态来自后端。
3. 同一股票、行情快照、分析类型及策略已有进行中任务时，继续查看该任务，避免重复生成。切换页面、刷新或重新登录后恢复本人任务。
4. 生成过程中可以切换类型、查看旧报告；正在生成的范围内禁用再次提交。重新生成成功后增加一份历史，原报告保留。
5. 资料完整时正常展示；资料不完整但足以分析时，展示有限结论和具体缺失说明；完全无法分析时显示失败原因及重试入口，并保留原有报告。

## 报告内容

| 区域 | 展示内容 |
| --- | --- |
| 报告信息 | 股票、分析类型、适用策略、生成时间 |
| 数据时间 | 行情截至日期、资料获取截至时间分别展示，时间按北京时间呈现 |
| 资料质量 | 完整或不完整，以及对判断范围有影响的缺失说明 |
| 当前建议 | 明确告诉用户现在建议怎么做，给出一句主要理由 |
| 基本面默认内容 | 一条机会和一条风险，优先提示重要股东减持事项 |
| 筹码默认内容 | 成本分布图、当前价格、上下参考区及一句解释 |
| 买卖建议默认内容 | 参考买入位置、触发条件、失效或退出参考；等待状态明确说明 |
| 详细依据与来源 | “为什么这样建议”及引用资料默认折叠，可展开条件、指标、正文与原文链接 |
| 历史与复制 | 查看本人已生成报告，分别复制摘要或全文，均包含来源、时间和缺失说明 |

资料质量按当前分析需要判断，“完整”不表示预测一定正确。资料可能晚于行情日期，报告不能被解释为行情日期当时已知的研究结论。

## 模拟版复审路径

全部数值、来源名称及来源时间为虚构样例，不执行真实检索或 AI 调用。来源链接仅指向公开披露入口，页面有明确说明；正式报告需要引用实际取得的资料原文。

1. 登录后进入任一个股详情，打开 AI 分析，先检查是否有明确的当前建议，再检查一条机会/风险、筹码图及买卖建议价格卡片；详细依据和来源应默认折叠。
2. 点击“生成分析”，观察阶段变化；处理中切换到规则页再返回，或刷新后重新打开 AI 分析，确认恢复同一任务。
3. 在“演示场景 → AI 分析”选择“资料不完整”，重新生成基本面报告，确认股东减持风险显示未核验，而不是没有风险，且保留旧历史。
4. 选择“分析失败”，重新生成，确认失败不会替换旧报告；点击“重试生成”，模拟恢复为资料完整场景，并创建新任务。
5. 生成中退出再登录原账号，确认恢复；切换其他账号确认看不到原账号任务和报告。
6. 切换买卖建议中的等待策略，确认显示突破观察价而不是立即买入；检查普通新闻缺失时仍保留技术建议。
7. 选择历史、复制摘要或全文，并在窄屏下检查价格、图形及展开内容。来源入口只核对链接行为，不用于核验虚构样例。

模拟任务按受理时间恢复：约 12 秒完成，失败场景约 6 秒结束。数据只保存在当前浏览器；关闭页面后不会发生真实后台执行，下次读取时按已过时间恢复演示状态。

接口以 [AI 分析接口](../api/analysis/README.md)为准；本轮完成模拟前端复审后再开展真实 AI 对接。
