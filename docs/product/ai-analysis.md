# 个股 AI 分析交互评审

分析内容及通用买卖规则见 [AI 分析设计](ai-analysis-design.md)。本期仅实现后端模拟分析；真实模型、联网资料与报告导出后续接入。

## 流程

1. 左侧“个股分析”输入名称或代码，结果显示名称、代码、交易所及资料状态，选定股票进入个股分析页；搜索完整目录，与机会筛选条件无关。
2. 搜索入口默认打开通用买卖建议；机会入口可沿用已入选策略。基本面、筹码和买卖建议共用现有详情、任务及个人历史。
   K线作为个股通用行情区域置于规则与AI页签上方，默认展开、可收起；切换页签不重置周期、均线和浏览位置，图表与报告沿用同一行情快照。
3. 主动生成后展示准备资料、模拟分析和整理报告；刷新、切页和重新登录可继续查看本人任务。相同输入进行中的任务继续查看，失败保留旧报告。
4. 默认只显示当前建议与一句理由；基本面机会/风险各一条，筹码先看图，买卖建议先看参考位置与风险复查位。详细指标、条件及来源折叠。
5. 显示行情日期、资料时间和模拟标识。不存在的股票、未覆盖市场、尚未同步的行情及分析所需资料不足分别说明；十年回补不阻塞已有数据分析。本期准备资料读取本地已同步数据，未同步股票明确等待行情更新，不调用实时取数或联网研究。

## 验收重点

- 名称、代码搜索均能找到未入选策略的股票；快速输入、空结果、刷新返回和手机布局可用。
- 未入选股票能生成通用买卖建议；已入选股票可切换通用与策略分析，两类历史与进行中任务不混合。
- 新股或资料缺失时不补造买入价、筹码图、财报或减持结论。
- 模拟任务与报告由后端保存，不调用真实模型、网页或搜索服务；普通用户可使用，其他用户不能读取本人报告。
