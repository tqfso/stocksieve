# AI分析报告设计

报告面向股票入门用户，统一使用真实模型、公告原文和程序计算。默认提供精简结论，证据与计算细节按需展开。

## 入口与历史

“个股分析”按名称或代码搜索全部已覆盖股票，不要求入选策略。规则、筹码与报告共用行情快照；新报告失败保留旧报告，刷新恢复个人历史。旧报告沿用原内容与标识，不改写为新版。

## 精简内容

摘要约100～180字，最多200字，回答当前怎么看及主要原因。区分新买入判断和已有持仓的观察建议，补充最多两条后续观察条件。

正文统一六章，每章一句结论及约80～160字依据，最多240字。缺少公司公告时，前两章调整为已知公司资料与已有数据观察，不把行情信号当作公司经营优势：

| 章节 | 回答什么 |
| --- | --- |
| 公司做什么 | 主要业务及有依据的公司类型 |
| 有什么优势 | 已有产品、技术或经营优势，不把标签当护城河 |
| 主要风险 | 最影响当前判断的两三项风险 |
| 已有持仓怎么办 | 持有者应关注什么，不盲目补仓 |
| 现在适合买入吗 | 合并买入与不买：当前判断、尚缺条件、何时继续等待 |
| 何时考虑卖出 | 投资逻辑失效、风险事件或价格观察条件 |

少用术语，不重复堆放同一风险，不在正文输出内部字段名或程序时间格式。条件使用实际资料或已定义规则，不由模型随意编造交易阈值。

## 事实与缺项

模型读到的数值连同原文、页码、单位、报告期和口径一起核对。摘要、正文、指标、股东信息和两种导出共用这些事实。

- 财务优先展示已有的当期收入、归母与扣非利润、经营现金流及对应同比。单季与累计数据分清，母公司与合并口径不混用。
- TTM使用本年累计＋上年全年－上年同期；缺期间时准确说明缺项，不把前三季度利润当TTM，也不笼统声称没有财报。亏损时PE不适用。
- 股东户数已知本期就展示。本期与上次统计日期及普通股/A股口径一致后才计算变化；缺上次不影响展示本期。户数变化不直接证明主力增减仓。
- 行业PE等尚无可靠资料的字段集中列入资料范围，不展示一排未知指标，不推定低PE就是便宜。
- 重要风险未核实时保留具体缺口，不因减持或诉讼资料不足而覆盖已经核对的经营结论。

行情日期、财报截止日、披露日和获取时间分别保留。后取得的资料不能解释为历史当时已知信息。

## 事件与计算

发现历史减持计划后按需追查进展、完成、终止公告，核对同一股东和计划。计划窗口结束不代表已实施完成；未找到公告不代表没有风险。诉讼区分涉诉、进展和裁判。

默认只展示一次技术情景盈亏比，注明观察价、上下方参考及费用口径。历史高低价不是目标价或保证成交的止损价。未计费用不称为净收益；理论盈亏平衡胜率留在页面计算说明中，不在摘要或正文突出展示。

渠道暂不可用时，仅可复用24小时内的已抓取公告索引，保留原获取时间并明确未覆盖之后的新披露；不重置渠道冷却。深市优先交易所官方公告，命中后停止补源，不从新浪重复下载。公司公告暂缺仅限制对应判断，不阻断整份报告。

资料渠道和查询配方集中维护在[股票分析技能](../../backend/skills/stock-analysis/SKILL.md)，不在本文重复。

## 页面与导出

页面先展示精简结论、持仓观察及后续条件，再按需展开六章、已知指标、资料范围、计算说明和来源。股东户数在公司资料中展示；独立筹码页继续只提供成本分布估算。

Word/PDF使用当前选中的已保存报告，包含精简正文、已知指标、资料范围和可点击引用，不重新分析或联网。两种格式统一北京时间、清晰标题与页码，避免重复编号、来源标题和冗长URL。高级计算明细在页面按需查看，独立筹码图不自动附在导出中。

报告和下载仅所属用户可访问，管理员也不能读取他人报告。

## 验收

六章完整且买入与不买合并；文字长度受控；已取得数字各处一致，缺项准确；不接受错误单位、期间、口径及无原文数值；重要事件有时间边界；页面、Word/PDF与引用一致，历史报告仍可读取和导出。
