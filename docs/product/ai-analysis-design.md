# AI 分析设计

面向缺少投资经验的用户，三类分析均由 AI 结合实际取得的资料形成结果。默认先给用户容易理解的结论，详细指标和来源按需展开。本文定义分析内容；交互流程见 [专项评审](ai-analysis.md)，接口见 [AI 分析接口](../api/analysis/README.md)。

## 1. 共用原则

- 同步行情和策略快照作为价格、量价及技术规则依据；财报、公告和新闻按需要联网补充并缓存。
- 指标、估算和参考价由可复查的计算产生；AI 组织机遇、风险和条件说明，每项事实保留实际来源，无法确认的内容明确标注。
- 分别展示行情日期、资料获取时间和公告发布时间。后取得的资料不能解释为行情日期当时已知的信息。
- 资料不完整但足以提供有限分析时说明判断范围；缺少核心数据时不给出无法支持的结论或价位。
- 默认直接给出“可以考虑、先等待、暂不买”等当前建议，以及一句主要理由；由 AI 综合已核验资料作判断，用户无需再从指标中自行推导。
- 每类摘要使用简短白话，机会和风险各优先展示一条；允许“暂未发现明确机遇”，不为填满版面编造利好。

## 2. 基本面：机会与风险

关注经营增长、盈利质量、现金回收、估值与重大股东行为。默认展示两组短提示：值得继续关注的机遇，以及可能影响判断的主要风险。TTM、PE 等指标及计算口径放入详细依据。

**大股东减持是必查风险项**。优先核对交易所、公司公开披露的计划、进展、结果及变更公告，追溯仍未结束的计划，保留已检索的时间范围。

| 信息 | 判断要求 |
| --- | --- |
| 股东与计划 | 明确股东身份、计划数量上限、披露日和适用期间 |
| 减持比例 | 保留公告口径，区分占总股本比例与占该股东持股比例 |
| 实际进展 | 区分拟减持与已披露实施，不将计划上限当作实际数量 |
| 当前状态 | 按公告区分计划、实施中、完成、终止或待核验；不能仅因日期已过认定完成 |

摘要优先提示尚未结束或进展不明的重要减持事项，详细依据列明来源及影响范围。同一计划的多次进展不重复计数，不将不同股东或不同计划混算。

未检索到相关公告，不等于不存在减持风险。无法取得足够资料时显示“股东减持风险未核验”，保留未知状态；不得因此给出“没有减持风险”的结论。

## 3. 筹码：先看图

- 核心输入为已同步的历史价格、成交量/额、换手率与复权数据，形成可复查的成本分布估算。
- 默认展示价位—占比图，突出当前价格、下方参考区和上方参考区，配一条简短解释；计算指标和方法放入详细依据。
- 联网资料仅按需补充股本变化或事件背景，查不到普通新闻不阻断基于已有量价数据的估算。
- 历史不足以形成分布时不展示虚构图形；成本分布不等同真实持股清单，参考区不保证价格反弹或受阻。

## 4. 买卖建议：先看价格和条件

页面名称为“买卖建议”，接口类型保持 `trade`，沿用用户选定的[策略](strategies/README.md)。默认展示参考买入价或区间、需要满足的条件，以及失效或退出参考。

| 策略 | 参考位置与条件 |
| --- | --- |
| 短线 | 以突破参考价为锚，观察回踩守住与成交变化 |
| 波段 | 关注20日均价附近，结合缩量和重新走稳的条件 |
| 长线 | 关注60日均价附近及长期趋势是否保持；动态均价不能永久固定 |
| 趋势埋伏、低位筑底 | 展示突破观察价和区间下沿；未确认突破时明确等待，之后重新检查短线全部条件 |

价位与条件须处于同一行情和复权口径，依据、适用策略及失效条件保持一致。价格未达到条件时给出等待或重新评估的建议；无法支持目标价时不编造确定的买入或止盈价。

默认只突出当前建议、买入参考和失效/退出参考。看好哪些因素时可以考虑、在意哪些风险时先别买，以及触发条件放入“为什么这样建议”，供需要时展开；不推定用户的风险承受能力。

公告和新闻只补充事件风险，**不作为生成技术分析的强制前提**。未取得事件资料时保留基于同步行情的技术建议，并说明事件风险未核验；公告内容不直接改写规则筛选结果。

当前模拟版的价格区间只用于交互评审，不能视作新增或已回测的交易规则。正式建议需结合真实输入验证其计算及观察方法。

## 5. 展示与后续扩展

所有类型先显示明确的当前建议。基本面随后显示一条机会与一条风险；筹码以图为主；买卖建议突出两个参考价。详细指标、条件、正文和引用资料折叠展示，摘要和完整内容分别支持复制，影响当前建议的重要缺失说明始终可见。

后续研究报告文档复用相同的结构化结果和图表。智能体框架、技能执行、模型适配及任务约束遵循[后端概要设计](../design/backend.md)，不在产品文档重复实现细节。
