# AI 分析报告设计

本文定义统一报告与独立筹码的产品规则。当前已实现七章模拟报告、独立筹码展示和 Word/PDF 导出，真实模型与联网资料后续接入。

## 1. 功能与入口

个股详情保留共用的 K 线区域，下方并列三个功能：**规则筛选结果、筹码分布、AI 分析报告**。

- 名称或代码搜索面向完整股票目录，不要求入选策略；搜索入口默认进入 AI 分析报告，机会入口默认进入规则筛选结果。
- 一次生成一份完整报告，不再让用户分别选择基本面、筹码和买卖建议。已入选策略作为报告背景，不再拆成不同策略的报告入口。
- 筹码分布直接读取同一行情快照的计算结果，无需生成 AI 报告；AI 可以引用筹码指标作依据，但独立筹码图不嵌入报告正文。
- K 线、筹码和规则沿用所选行情快照；切换功能保留图表周期和浏览位置。查看历史报告时明确其引用的行情日期，不与最新数据混淆。

## 2. 输入资料

| 来源 | 内容与要求 |
| --- | --- |
| 数据库与计算结果 | 股票身份、行业题材、股价、成交量额、换手率、总市值、MA5/10/20/60（需要时MA120）、历史走势、筹码分布，以及已同步的业绩和估值资料 |
| 公司与行业公开资料 | 行业景气、公司业务与业绩、竞争优势及壁垒、诉讼与处罚、股东户数变化、股东减持计划及实施进展、券商评级与目标价、近期市场关注方向 |
| 行业估值 | 公司所属行业的市盈率、行业分类、估值日期、计算口径与实际来源，用于与公司估值比较 |

市盈率明确区分静态 PE、PE（TTM）与动态 PE；动态 PE 保留其实际采用的盈利口径，不把 TTM 当成动态 PE。当前代码只具备 PE（TTM）计算能力，数据库没有的估值或财报不能假定已同步，后续补采或核验后才展示。

公司与行业对比采用**相同 PE 口径、可比日期及明确行业分类**，展示两者数值、相对高低和简短解释。行业整体值、中位数等统计口径分别标明；无法确认可比性时提示不可直接比较。盈利为零、负数或资料缺失时不给出误导性的估值倍数，也不单凭低 PE 判定可以买。

价格、均线、筹码和买卖参考价采用一致的行情及复权口径。指标与筹码由程序计算，AI 综合解释，不由模型补造数值。

## 3. 报告内容

报告固定回答以下七个问题；每项先给一句明确结论，再提供简短理由及可展开的证据。

| 章节 | 用户看到的内容 |
| --- | --- |
| 1. 公司基本资料 | 名称、代码、上市板块、所属行业、主营业务与公司类型；包含本期/上期股东户数、变化比例、统计及披露日期、来源与集中趋势，缺失时逐项标明 |
| 2. 优势与市场关注 | 公司靠什么竞争、壁垒是否成立；当下市场关注什么行业、题材或事件，区分长期优势与短期叙事 |
| 3. 问题与风险 | 业绩、估值及行业对比、经营与财务、股东户数与持股集中趋势、诉讼处罚、减持、周期和题材兑现等主要问题，优先列出影响当前建议的风险 |
| 4. 是否建议持有 | 面向已持有者明确给出持有、谨慎持有、考虑减仓或不建议持有等判断及原因；无法判断时直说资料不足，不把持有建议等同新买入建议 |
| 5. 何时适合买入 | 买入前提、价格区间及依据；价格到位仍需满足哪些条件，资料不足时不给虚构区间 |
| 6. 何时不适合买入 | 明确列出不应参与的情形，例如逻辑未兑现、估值或价格条件不符、关键风险未排除，并与当前建议一致 |
| 7. 买入后何时卖出 | 分别说明投资逻辑失效、风险事件与价格条件，以及满足什么条件可考虑止盈或退出；有可靠依据才给数值 |

“期权型公司”指主业或新业务的潜力尚未兑现、潜在空间大但不确定性高的公司，不指交易所股票期权。不能只凭热门题材就认定为期权型公司。

市场关注方向须有题材、行业表现或公开资料依据；对资金意图的解释标为推测，不能把日线量价估算当成已确认的资金行为。券商目标价单独列明机构、报告日期、适用期限（已披露时）与来源，不等同本产品建议的买入价或收益承诺。

重要股东减持检查计划、进展、结果及变更，区分拟减持上限与已实施数量；诉讼区分涉诉、进展和裁判结果。未检索到资料不代表没有风险，重要事项未核验须直接提示。

## 4. 展示与资料链接

面向小白，默认先看**持有建议、买入条件与区间、主要风险、卖出条件**。七个章节均可定位阅读，详细指标、计算说明和完整证据折叠，避免一次展示大段专业内容。

- 展示股票名称、代码、行情日期、资料获取截至时间、报告生成时间及模拟标识。
- 事实结论与实际引用资料对应，正文可点击引用编号查看原文；来源列表包含标题、发布机构、原文链接、发布时间和获取时间。
- 优先采用交易所、公司公告和机构原文；仅有转载时注明转载，不能把搜索结果摘要或网站首页当作原文证据。
- 区分已核验事实、程序估算与分析判断；缺失及时间冲突明确展示。后取得的信息不能被写成行情日期当时已知的结论。
- 任务和报告按用户保存；刷新或重新登录恢复已有任务和历史，不自动重新生成。新报告失败不删除已有成功报告。

股东户数与筹码集中观察放在“公司基本资料”中，列本期/上期户数、变化比例、统计截止日、披露时间、来源及趋势判断，页面与导出一致。未采集时明确待核验，不能判断集中或分散。

关键指标增加“技术盈亏比（赔率）”，以所选快照收盘价为当前价，按（前20日高点－当前价）÷（当前价－前20日低点）计算，全部使用同一行情快照的前复权口径。当前价须严格处于两参考位之间，且现有技术窗口与交易状态可核验；否则显示“暂无可靠参考”。以当前价衡量继续持有的技术情景，不使用个人持仓成本。展示参考价格及口径，未计交易费用，不代表胜率、券商目标价或实际成交结果，不单独改变持有或买入建议；暂不提供未经回测支持的胜率百分比。

不单独展示“公司与行业市盈率对比”或“待核验与资料缺失”章节；估值放入关键指标，缺失在相应字段标明。

## 5. 独立筹码分布

筹码页与规则、AI 报告并列，使用已同步历史成交数据估算成本分布，展示现价、平均成本、获利比例、70%/90%成本区间及上下方筹码参考区。计算结果可作为 AI 的输入，查看图形不调用模型或联网研究。

股东户数只在AI报告的“公司基本资料”展示；独立筹码页仅提供成本分布估算，不展示股东户数。

标明“估算成本分布”，不等同真实持股清单；历史、换手率或复权资料不足时提示缺失，不展示虚构图。筹码缺失不单独阻断其他依据充分的报告章节，相关判断保留限制说明。

## 6. Word 与 PDF 导出

- 用户可为本人当前选中的成功报告选择 **Word（.docx）或 PDF（.pdf）** 格式导出；模拟报告同样支持导出。
- 文件包含报告摘要、七个章节、关键指标、来源链接和各项日期。公司与行业PE列入关键指标；资料缺失在对应字段或判断中标明，不另列缺失清单。
- 引用编号与来源列表对应，文档内原文链接可点击；模拟标识在标题及正文中保留。
- 导出使用已保存的该版报告与输入，内容与页面一致，不重新分析、不联网更新；独立筹码展示页不随报告自动导出。
- 仅报告所属用户可下载，管理员不能读取他人报告。导出失败可重试，不影响已保存报告。
- 两种格式内容一致。Word文件可正常编辑，PDF保留完整排版；中文字体、标题层级、跨页表格和可点击链接均须正常显示。

## 7. 分期范围与验收

当前提供统一的**模拟报告、独立筹码页及 Word/PDF 导出**。本地已有指标采用真实计算，七个章节可用模拟文字或“待核验”展示；公司类型、业绩、诉讼、减持、券商目标价和行业 PE 没有证据时不作真实判断。未联网时来源明确显示未检索，不虚构原文链接。

后续再接入真实模型与免费联网资料，沿用相同报告、引用和导出结构。模型协议、技能、频控和权限遵循[后端概要设计](../design/backend.md)。

验收重点：任意已覆盖股票均可生成统一报告；七项问题完整，未知不冒充事实；筹码不依赖 AI 任务；公司与行业估值可比或明确缺失；页面、Word与PDF引用一致、链接可用、模拟标识保留；他人无法读取或导出本人报告。
