# 选股策略设计

以下为 V1 初始设计，参数尚未经过回测。

| 策略 | 核心思路 | 观察周期 |
| --- | --- | --- |
| [短线](short-term.md) | 放量突破近期高点 | 3～10 个交易日 |
| [波段](swing.md) | 上升趋势中的缩量回调、企稳 | 2～8 周 |
| [长线](long-term.md) | 中长期趋势持续向上 | 3～12 个月 |
| [趋势埋伏](trend-wait.md) | 上升趋势中缩量整理，等待突破 | 1～4 周 |
| [低位筑底](base-wait.md) | 下跌后低位横盘，等待趋势修复 | 2～8 周 |

## 共用规则

- 收盘数据完整后计算，仅使用截至当日已知的数据，信号供下一交易日起观察。
- 日线窗口按交易日历计算；当日停牌、ST、退市整理股票不参与筛选，所需历史数据不足、缺失或均额为零时跳过。
- 最近 20 个交易日日均成交额不低于 3,000 万元。
- 价格使用截至计算日的统一前复权口径，成交额使用原始值；复查历史信号时，参考价换算到同一口径。
- 各策略同时满足全部入选条件才入选，每日重新计算；同一股票可以符合多个策略。
- 行业用于分类和筛选；AI 分析按需发起，规则筛选与 AI 报告分别展示。

## 计算口径

- `t` 为计算日，`t-k` 为此前第 k 个交易日。
- `C(t)`、`H(t)`、`L(t)`、`A(t)` 分别为收盘价、最高价、最低价、成交额。
- `MA(N,t)` 为截至 t 日、包含当日的最近 N 个交易日收盘价均值。
- `均额(N,t)` 为相同窗口内的成交额均值；“此前 N 日”不包含 t 日。

## 结果展示

共用信息包括股票代码、名称、交易所、上市板块、行业、策略和数据日期；各策略补充对应指标与入选理由。失效条件用于复查该次信号，观察周期用于说明策略定位。

## 策略关系

- 趋势埋伏要求 `MA20 ≥ MA60`，低位筑底要求 `MA20 < MA60`，两者同日互斥。
- 两类等待策略均要求收盘价未突破此前20日高点，与短线同日互斥；后续突破时，重新检查短线的全部条件。
- 趋势埋伏可与波段、长线重叠；低位筑底与波段、长线同日互斥。多个标签不表示已经验证成功率更高。
- 列表按当日条件重新筛选；等待策略展示“等待中”及突破、失效观察条件，不将未入选或跌出名单直接当作买卖信号。
