# 前端对接说明

[接口总览](README.md) · [通用约定](common/conventions.md)

1. 登录后调用 `/auth/me`、`/market/status`；无快照时展示数据准备状态，管理员可进入数据管理。
2. 有快照后获取策略说明和筛选选项，再查询机会列表；列表、详情、图表沿用快照 ID。
3. 发起 AI 分析后查询任务详情；生成成功再展示正文，切换类型时读取本人历史。
4. 管理员新增用户、修改密码；同步任务通过列表、详情和日志恢复展示，不依赖页面计时器推进。

当前前端模拟模型中的中文交易所、成交额与总市值“亿元”、信号平铺字段及 `success` 状态，需要在正式对接的数据层转换为[接口约定](common/conventions.md)。

换手率和总市值使用预设区间下拉框，所选区间转换为现有的 `minTurnover` / `maxTurnover`、`minMarketCap` / `maxMarketCap` 参数，包含上下边界；选择“不限”时省略两侧参数。市值下拉选项及页面网址使用亿元，调用正式 API 时须将区间边界乘以 `100000000` 转为元；接口返回的总市值展示时做相反转换。

演示场景开关、虚构行情生成和“重置演示”属于前端评审功能，无对应正式 API。
