# StockSieve V1 需求说明书

## 1. 项目目标

建设覆盖沪深北全 A 股的收盘后选股网站，包含前端、后端和项目文档。前端评审阶段使用完整模拟数据。

## 2. 数据管理

- 管理员从 Sina 或 Baostock 初始化全市场股票数据。
- 每天北京时间 18:00 自动同步，如果数据未完全就绪，任务自动延迟，支持手动触发同步。

## 3. 账号与权限

- 账号密码登录，分管理员和普通用户。
- 管理员负责数据同步、用户管理，可修改自身密码、新增普通用户。

## 4. 股票筛选与展示

- 提供短线、波段、长线机会。
- 支持上市板块、行业、题材/概念、换手率和总市值筛选；后两项使用预设区间下拉框，支持“不限”。
- 详情展示标准日、周、年 K 线，MA5、MA10、MA20、MA60、MA120 可分别开关。

## 5. AI 分析

- 按需分析基本面、筹码和买卖条件，在页面展示结论、指标、观察条件、风险及来源。
- 基本面资料按需联网获取，展示营业收入（TTM）、归母净利润（TTM）和 PE（TTM）。
- 筹码结果包含价位—占比图，标注估算支撑、压力及现价参考。
