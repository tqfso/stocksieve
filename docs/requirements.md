# StockSieve V1 需求说明书

## 1. 项目目标

建设面向股票入门用户的收盘后选股网站，包含前端、后端和项目文档，最终覆盖沪深北全 A 股。

当前上线范围为沪市主板、深市主板、创业板、科创板，北交所后续补充；行情使用免费真实数据，AI 分析统一调用真实模型。前端通过后端接口读写业务数据。新版统一AI报告、独立筹码展示和Word/PDF导出已实现，已有历史报告保留原标识。

## 2. 数据管理

- 管理员从已接入且支持对应任务的数据源中单选一个，执行初始化或数据更新；渠道可扩展，当前新浪提供证券基础和行情，百度提供行业及题材。
- 股票基础信息独立初始化、更新，保留已有分类关系。
- 行业、题材及股票归属使用独立任务和分类渠道；首次在股票初始化后同步，后续仅按需手动刷新，不更新股票基础信息。
- 股票基础信息和分类分别记录最近成功时间，失败保留上次成功数据；行业、题材不按日自动更新。
- 每天北京时间 18:00 自动同步收盘行情并计算策略，复用最近成功的分类关系；行情未完全就绪时延迟，支持手动提前触发。
- 新上市或尚未覆盖的股票暂标记分类未知，不阻塞行情同步，后续手动刷新补齐。

## 3. 账号与权限

- 账号密码登录，分管理员和普通用户。
- 管理员负责数据同步、用户管理，可修改自身密码、新增普通用户。

## 4. 股票筛选与展示

- 提供短线、波段、长线、趋势埋伏、低位筑底五类机会，规则见[策略设计](product/strategies/README.md)。
- 趋势埋伏关注上升趋势中的缩量整理；低位筑底关注下跌后低位横盘、停止创新低。两类均等待突破确认，展示区间上下沿、成交额比例及观察条件。
- 同一股票可有多个策略标签；同一列表内每只股票一行，展示所选策略的指标和入选理由。
- 策略数量随筛选条件变化；无筛选时为 0，提示当日暂无入选股票，并与筛选后无结果、加载失败分别展示。
- 支持上市板块、行业、题材/概念、换手率和总市值筛选；后两项使用预设区间下拉框，支持“不限”。
- 详情展示标准日、周、年 K 线，MA5、MA10、MA20、MA60、MA120 可分别开关。
- 个股详情的规则筛选结果、筹码分布、AI分析报告并列。筹码独立读取历史成交数据的估算结果，不需要生成AI报告；三者与K线沿用一致的行情快照。

## 5. AI 分析报告

- 独立“个股分析”入口按名称或代码搜索完整股票目录，当前覆盖沪深四板块，不以入选策略为前提；机会入口与搜索入口共用报告功能。
- 一次生成完整报告，替代基本面、筹码和买卖建议三类独立分析；规则信号和筹码指标作为输入，筹码展示页独立于报告。
- 从数据库准备股价、MA5/10/20/60、筹码分布、业绩及已同步估值；公司市盈率与行业市盈率按相同口径、可比日期和明确行业分类对比，缺失不补造。
- 联网资料覆盖行业与公司基本面、业绩、股东户数变化、诉讼、减持、券商目标价及市场关注方向；使用免费渠道、缓存和共享频控，展示实际引用的原文链接和资料时间。
- 报告回答公司基本资料与类型（成长、周期或期权型），包含股东户数及集中趋势、优势与壁垒及市场关注方向、问题与风险、是否建议持有、适合买入的条件和区间、不适合买入的条件、买入后的卖出条件。
- 默认提供简短明确的建议和主要理由，详细指标、证据和来源展开查看；重要资料未核验时直接说明，不让用户自行从大量数据推导结论。
- 保留可恢复任务和个人报告历史，新报告失败不删除旧报告；支持将当前选中的报告导出为Word（.docx）或PDF（.pdf），保留来源链接、日期、缺失说明及历史标识。
- 当前支持真实模型报告、独立筹码和Word/PDF导出；分析检索公告原文、阅读文档并使用金融计算，资料不足时保留限制说明。产品规则与验收要求见[AI分析报告设计](product/ai-analysis-design.md)。
