# StockSieve 前端模拟评审版

Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router。当前全部使用浏览器内的模拟数据，不调用后端、行情或 AI 服务。

## VS Code 编辑器

安装工作区推荐的 **Vue - Official** 扩展（`Vue.volar`），用于 Vue 组件、模板和 TypeScript 的检查与补全。如果通过 Remote SSH 或容器开发，将扩展安装在对应远程环境中。同一工作区启用 Vetur 时，请将其禁用，以免两套 Vue 语言服务同时检查。

安装依赖和扩展后仍有旧提示，可执行命令面板中的 `Developer: Reload Window`。项目包含 `.vue` 模块兼容声明；完整的组件类型检查使用后文的 `npm run build`。

## 启动与浏览

需要 Node.js 22.12 或更高版本。在项目根目录打开终端执行：

```bash
cd frontend
npm install
npm run dev
```

开发服务仅监听 `127.0.0.1:5173`。保持终端运行，在服务所在机器的浏览器打开 <http://127.0.0.1:5173>。

修改源码后页面会自动更新；终端按 `Ctrl+C` 停止服务。修改监听配置后，如果已有开发服务运行，先停止旧服务，再执行 `npm run dev`。此服务用于开发和评审。

如果代码运行在远程服务器，先在服务器启动开发服务，再在自己电脑的终端建立 SSH 转发：

```bash
ssh -N -L 5173:127.0.0.1:5173 root@172.21.21.98
```

`-N` 表示不执行远程命令，隧道建立后通常不显示额外输出，终端会保持等待。保持两个终端运行，在自己电脑浏览器打开 <http://127.0.0.1:5173>。如果本机 5173 端口已占用，将转发命令左侧端口改为 5174，浏览器访问 `http://127.0.0.1:5174`。

账号、演示密码、报告和同步任务保存在当前浏览器的 localStorage 中，不同浏览器或不同访问地址的数据不互通。请勿输入真实账号或常用密码；这些模拟会话与角色守卫仅用于交互展示。

## 页面与评审路径

| 页面 | 主要可操作内容 |
| --- | --- |
| 登录 | 两种角色、错误密码、空字段、创建后的新账号登录 |
| 机会筛选 | 三类策略、行业、概念、上市板块、换手率、总市值区间、搜索、排序、分页、策略说明 |
| 个股详情 | 规则信号、入选原因、指标、失效条件、多个策略切换 |
| K 线 | 日 / 周 / 年 K，成交量，MA20 / 60 / 120，十字光标，拖动，缩放 |
| AI 分析 | 基本面 / 筹码 / 买卖条件，按需生成、失败重试、历史记录、复制 |
| 数据管理 | 选择示例数据源、初始化、收盘同步、进度、日志、失败重试 |
| 用户管理 | 搜索、角色筛选、创建普通用户、重复账号与表单校验 |
| 修改密码 | 旧密码校验、确认新密码、成功后重新登录 |

建议按以下顺序评审：

1. 用管理员登录，切换三类策略，组合筛选并进入个股详情；换手率和总市值通过预设区间下拉框选择，可清空或选择“不限”；返回列表检查条件是否保留。预设区间包含上下边界，旧网址保存的其他范围会显示为“已保存”选项。
2. 切换 K 线周期，缩放、拖动、开关均线，再查看不同规则信号。
3. 发起三类模拟分析，刷新页面查看报告历史。
4. 打开右上角“演示场景”，分别体验空结果、列表失败、AI 失败及恢复。
5. 在数据管理中先初始化，再同步；切换页面查看任务继续运行，模拟失败后重试。
6. 创建普通用户，退出并用新账号登录，确认仅出现普通用户可用的导航；直接访问 `#/admin/data` 应返回机会列表。
7. 用管理员修改密码，验证旧密码失效和新密码可登录。

评审反馈注明“页面、操作、实际表现、期望变化”即可，也可以附截图。右上角“演示场景 → 重置演示”能清除本浏览器的演示修改并退出账号。

## 模拟数据边界

- 固定行情日期为 2026-10-28，价格、指标和股票覆盖数量均为虚构；未执行真实策略计算或回测。
- K 线由固定种子生成工作日样例，周 / 年线由样例聚合，不包含真实交易日历。当前使用本地 SVG 交互组件，专业 K 线库后续验证后可替换此组件。
- AI 报告为本地示例文本，来源明确标注为模拟资料，不获取真实财务或筹码数据。
- 同步由前端计时器驱动，任务记录不会改变固定机会样例；刷新或退出账号会中断未完成任务，并可重试。
- 服务器对接及真实鉴权在后端接口开发完成后开展。模拟业务集中在 `src/mock/`，便于之后替换数据层。

## 检查与构建预览

```bash
npm test
npm run build
npm run preview
```

测试使用 Node.js 内置工具，覆盖数据筛选、K 线聚合、模拟账号权限、报告隔离及任务状态转换。构建命令先做 Vue / TypeScript 类型检查，再生成 `dist/`；预览地址为 <http://127.0.0.1:4173>。远程预览可将前面的 SSH 转发命令两侧端口都改为 4173。

正式静态托管使用 `dist/` 目录，默认部署在站点根路径。当前采用 hash 路由，可直接刷新详情页。正式服务器的域名和托管配置等评审完成后再确定。
