# StockSieve 前端

Vue 3、TypeScript、Vite、Element Plus、Pinia。正式页面使用真实后端接口，不生成行情、用户或任务数据；AI报告由后端模拟并明确标记。

## 启动与访问

需要Node.js 22.12以上，在仓库根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

开发地址为`http://127.0.0.1:5173`，`/api`代理到本机8000端口。正式构建由Docker中的API同源提供，服务器地址为`http://127.0.0.1:8000`。

远程服务器可在客户端转发端口后访问：

```bash
ssh -N -L 8000:127.0.0.1:8000 root@172.21.21.98
```

保持隧道运行，浏览器打开`http://127.0.0.1:8000`。正式启动、日志与数据库维护见[部署说明](../docs/deployment/backend.md)。

## 账号与数据

初始管理员为`admin`，随机口令保存在服务器`backend/.state/initial-admin.json`私有文件中，不使用演示密码。普通用户由管理员创建；改密会撤销旧会话。

当前覆盖沪深四板块，北交所后续补齐。初始化、行业题材、收盘策略为三个真实后台任务；关闭页面不会取消已受理任务。首轮历史补齐遵守源频控，完整校验后发布快照。

列表、详情、图表和分析沿用同一快照；价格为元，成交额/市值在页面转换为亿元。空库展示准备状态；缺资料显示未知，对应不可用筛选禁用。分类资料时间可能晚于行情日期，分别标明。

K线及均线均读取后端结果，支持日/周/年、历史分页、拖动和缩放；历史不足的均线为空，不补造走势。AI任务、模拟标识与报告历史也来自服务器，浏览器只展示、轮询与复制。

## 检查

```bash
npm test
npm run build
```

测试覆盖HTTP客户端的会话、权限错误、单位、空值、固定快照和幂等重发。`src/mock`仅保留为旧评审数据与回归夹具，正式页面不导入。浏览器与真实PostgreSQL/HTTP验收命令见[后端说明](../backend/README.md)。

主题样式集中在[theme.css](src/theme.css)，布局在[style.css](src/style.css)。VS Code推荐Vue - Official扩展；远程开发时安装在远程环境，旧诊断可通过`Developer: Reload Window`刷新。
